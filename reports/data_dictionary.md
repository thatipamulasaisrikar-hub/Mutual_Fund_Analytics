# Data Dictionary

## fund_master

| Column | Description |
|----------|------------|
| amfi_code | Unique AMFI Scheme Code |
| scheme_name | Mutual Fund Name |
| fund_house | AMC Name |
| category | Equity/Debt |
| sub_category | Scheme Type |

## nav_history

| Column | Description |
|----------|------------|
| amfi_code | Scheme Code |
| date | NAV Date |
| nav | Net Asset Value |

## investor_transactions

| Column | Description |
|----------|------------|
| transaction_type | SIP/Lumpsum/Redemption |
| amount | Transaction Amount |
